# FFB-Master (sample font)

A decomposed Arabic design that demonstrates the FFB pipeline: 521 glyphs, of which 388 are encoded (the letters themselves are empty glyphs; GSUB replaces them with skeletons and marks at run time).

| Path | What it is |
|---|---|
| `FFB_Master.otf` | the built font |
| `source/FFB_Master.ufo` | the UFO source (skeletons, marks, anchors) |
| `build/gsub.fea` | `isol/init/medi/fina`, generated by FFB from the decomposition table |
| `build/gpos_mark.fea` | `mark` + `mkmk`, generated from the anchors |
| `build/gpos_curs.fea` | `curs`, generated from the `Ex` / `_Ex` anchors |
| `build/decompose_table.yaml` | the letter → skeleton + marks table |
| `build/hand_written.fea` | the author's hand-written `calt` and `kern`, with the classes they use |

## Rebuild

From this folder:

```
python3 ../src/ffb.py source/FFB_Master.ufo --out rebuild --extra-fea build/hand_written.fea
```

This renames the anchors to the FFB convention (the source still uses FontLab names such as `T`, `_T.mrk`, `D`, `R`, `S`), generates the features and compiles `rebuild/FFB_Master.otf`. The result has the same glyph order as the shipped font.

## Notes on the source

- Glyphs are closed outlines. (An older single-line version of this design had open paths; `build_otf.py` refuses those.) One stale open contour in `yehRohingya-ar` was removed from this copy.
- `hehgoal.init.skl` and `hehDoachashmee.isol.skl` still carry Unicode values (U+FBA8, U+FBAC). Skeletons should have none; they appear in the font as `uniFBA8` / `uniFBAC`.
- `alef.fina.skl.ss01` has its cursive entry anchor at x=384 while its advance is 243. This is intentional: the outline extends to x≈404, and the anchor makes the alef tuck into the preceding lam.
